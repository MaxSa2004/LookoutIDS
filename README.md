## Overview

LookoutIDS is a network intrusion detection system (IDS)
designed to monitor network traffic, detect suspicious activity,
and send real-time security alerts to Discord.

## Features

- Network traffic monitoring
- Suspicious activity detection
- Real-time Discord notifications
- Configurable detection rules
- Event logging and analysis
- Real-time Discord notifications
